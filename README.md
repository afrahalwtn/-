# شركة أفراح الوطن للتجارة العامة — نسخة التطوير

نظام ويب تجريبي للمواد والجرد وتنبيهات انخفاض المخزون وعروض الأسعار والصلاحيات المحددة للمستخدمين. واجهته عربية ومتجاوبة، ويعرض شعار Tapello الأصلي.

## التشغيل الصحيح لهذه النسخة على GitHub

هذا المستودع يعمل عبر **Node.js / Express** في الملف `server.ts` مع **SQLite محلية** من مكتبة Node المدمجة (`node:sqlite`). يحتاج Node.js **22.16 أو أحدث**، ويفضّل نسخة LTS حديثة. لا تحتاج قاعدة البيانات إلى حساب أو خدمة سحابية.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` ما لم تضبط متغير `PORT` بعنوان مختلف.

## دخول نسخة العرض

- اسم مستخدم الإدارة: `admin`
- كلمة مرور العرض فقط: `admin123456`
- حساب العامل التجريبي: `staff` / `staff123456`

**تحذير أمني:** كلمات مرور العرض أعلاه معروفة؛ لا تصلح للاستخدام التجاري، لكنها تُخزَّن الآن في SQLite على شكل بصمات `scrypt` مملّحة، وليست كلمات مرور نصية.

عند تشغيل قاعدة جديدة في وضع `NODE_ENV=production` يجب توفير `AFRAH_ADMIN_PASSWORD` و`AFRAH_STAFF_PASSWORD` بكلمتين قويتين **قبل أول تشغيل**. لا تشاركهما أو تضفهما إلى GitHub. تغيير هذين المتغيرين بعد إنشاء القاعدة لا يغيّر كلمات مرور الحسابات المخزنة تلقائياً.

## قاعدة البيانات المجانية وتشغيل الأجهزة

أصبحت **SQLite مرتبطة فعلياً بالخادم**: تحفظ المواد، وصفها وصنعها وكمياتها وأسعارها، والمستخدمين وصلاحياتهم، وعروض الأسعار مع تفاصيلها. يتم حفظ التعديل مباشرة، ولا يُعاد تحميل بيانات العرض التجريبية بعد أول إنشاء للقاعدة.

- ملف قاعدة البيانات: `data/afrah.sqlite`.
- الصور: `data/images/`، مع حفظ أسماء الملفات في القاعدة.
- يمكن تحديد مسار التخزين الدائم عن طريق `AFRAH_DATA_DIR` على حاسبة الشركة.
- لا تُرفع ملفات قاعدة البيانات والصور إلى GitHub؛ يستثنيها ملف `.gitignore`.
- تتم كتابة SQLite بنمط WAL؛ احتفظ بنسخة احتياطية متسقة لملف القاعدة ومجلد الصور. **لا تنسخ ملف .sqlite وحده أثناء استمرار الكتابة من دون طريقة نسخ احتياطي تدعم WAL.**
- الأجهزة التي تتصل بنفس خادم الشركة على شبكة واي فاي محلية تشترك في نفس البيانات، ولا تحتاج تثبيت تطبيق، لكن يجب إبقاء الخادم شغالاً.
- المعاينات السحابية المؤقتة، ومنها بعض بيئات Google AI Studio، **قد تمسح الملفات عند إعادة التشغيل/إعادة النشر** ما لم تُضبط وحدة تخزين دائمة. لذا لا تحفظ بيانات الشركة الحقيقية في معاينة مؤقتة.

هذه النسخة تبدأ بخمس مواد تجريبية عند إنشاء قاعدة جديدة. **الـ4,000 مادة الحقيقية لم تُستورد بعد**؛ أُجري اختبار مستقل على أكثر من 4,200 مادة تجريبية. البيانات التي كانت حصراً في ذاكرة إصدار قديم لا تنتقل إلى SQLite تلقائياً.

## البحث العربي المرن

يستخدم الويب والخادم نفس الملف `web/arabic-search.js`، الذي يوحّد أثناء البحث فقط:
`أ، إ، آ، ٱ` مع `ا`؛ `ة` مع `ه`؛ `ى` و`ی` مع `ي`؛ `ک` مع `ك`؛ التشكيل والمد؛ والأرقام العربية/الفارسية مع الغربية. يقبل كلمات البحث بترتيب مختلف. **لا يعدّل أسماء المواد المحفوظة**. لا يشمل بعدُ جميع الأخطاء الإملائية العشوائية أو تبديل حروف غير متكافئة.

## فصل لوحة الإدارة عن بوابة الموظف

- **`/admin`**: لوحة الإدارة المستقلة، لها صفحة دخول وشيفرة واجهة منفصلتان. المسؤول وحده يستطيع إدارة المواد والأسعار والجرد والتنبيهات والصلاحيات وعروض الأسعار.
- **`/`**: واجهة الموظف المنفصلة، لا تضم نماذج تعديل المواد أو إدارة المستخدمين أو العروض الإدارية المحفوظة.
- **«جهّز قائمة» متاحة للاثنين**: يبحث المسؤول أو الموظف عن مواد متعددة، يضيفها إلى جدول Tabulator، يغيّر العدد داخل الخلية، ويحذف المواد.
- **أسعار الموظف**: عمود سعر الشراء أو البيع وإجمالياته يظهر فقط إذا فعّلت الإدارة صلاحية عرضه. الحماية من الخادم أيضاً، وليس مجرد إخفاء بصري.
- **عروض الأسعار الرسمية وحفظها**: للإدارة، مثل المتفق عليه. الموظف يستطيع طباعة قائمته، بما فيها الأسعار المسموح له بمشاهدتها، دون صلاحية إنشاء عرض إداري محفوظ.
- الواجهتان تشتركان في قاعدة SQLite نفسها؛ فصلهما هنا **فصل واجهة ومسار دخول وصلاحيات** على خادم واحد، وليس موقعين على خادمين مستقلين.

## الواجهة الجديدة والمصادر المجانية

- **القالب الحقيقي:** Tabler Dashboard وTabler Icons، بترخيص MIT ومكونات محلية تعمل أوفلاين.
- **الخط:** تجوال Tajawal بأوزان 400–900 (ترخيص OFL 1.1).
- **الألوان:** كحلي عميق، أزرق كهربائي، سماوي، وأبيض؛ مع لون ذهبي محدود للتنبيهات.
- **شعار Tapello:** SVG أصلي مفرغ من الخلفية، ولا توجد بطاقة بيضاء خلفه.

### الرئيسية والهيدر

شعار Tapello الأصلي المفرغ ظهر الآن **في منتصف الشريط العلوي** على الحاسبة والآيباد والموبايل. الترحيب منفصل في بطاقة Tabler الرسمية (card / card-body / card-status-top) بدلاً من لوحة كبيرة بداخلها الشعار. الرئيسية تحتوي فقط على الترحيب والبحث وتنبيهات المخزون.

### جهّز قائمة — جدول مثل إكسل

صفحة مستقلة للإدارة باسم **جهّز قائمة**، تستخدم مكتبة Tabulator الحقيقية المفتوحة المصدر (MIT)، مستضافة محلياً بدون اتصال خارجي. يبحث المستخدم عن مواد متعددة ويضيفها إلى جدول واحد؛ الأعمدة: التسلسل، الصورة، اسم المنتج، الوصف، الصنع، العدد القابل للتحرير، سعر الوحدة، الإجمالي، الحذف. يمكن ترتيب الصفوف حسب الأعمدة، والجدول يحسب الإجمالي. عند حفظ العرض يرسل نفس البيانات إلى واجهة عروض الأسعار الموجودة سابقاً.

### عروض الأسعار

صفحة مستقلة للعروض المحفوظة: عرض كامل، صورة المادة، الوصف، الصنع، العدد، السعر، والطباعة أو الحفظ PDF. لا تنشئ صفحة «جهّز قائمة» وظائف تجارية جديدة خارج طلب المستخدم.

### ملفات الواجهة المستخدمة

- `web/styles.css` — أنماط الأساس.
- `web/tabler-afrah.css` — تكييف Tabler للاتجاه العربي.
- `web/koa-theme.css` — الألوان الكحلية والزرقاء.
- `web/afrah-clean.css` — تنسيق الأساس للبحث والنوافذ.\n- `web/afrah-layout-v5.css` — تنسيق الهيدر والترحيب والجدول التفاعلي (آخر ملف بالترتيب).\n- `/vendor/tabulator.min.css` و`/vendor/tabulator.min.js` — مكتبة جدول مجانية محلية.
- `web/icons.js` — الأيقونات الأصلية.
- `THIRD_PARTY_LICENSES.md` — المراجع والتراخيص.

### الاختبارات

يعمل اختبار الخادم والتحقق من الصورة وعرض الأسعار، بالإضافة إلى اختبار Chromium الفعلي لتسجيل الدخول، وتعدد المواد في الوصل، وضبط الكميات، وحفظ العرض، وعدم تمدد الواجهة على الموبايل والآيباد والحاسبة. تعرض GitHub Actions صوراً للمعاينة باسم `afrah-ui-previews` عند نجاح سير العمل.

## معاينة Google AI Studio

تحديث الملفات على GitHub لا يعني أن معاينة Google AI Studio قد سحبتها تلقائياً. عند ربط المشروع بالمستودع، افتح إعدادات GitHub في Google AI Studio واسحب آخر التغييرات (Pull) من الفرع `main`. إذا لم يكن المستودع مرتبطاً، استورده من خيار Import from GitHub. راجع أي تعارضات قبل تأكيدها.

## المدى المطلوب فقط

1. حساب إدارة كامل وصلاحيات عرض أسعار الشراء والبيع لحساب المستخدم الثاني.
2. إدخال المواد والصور والأوصاف والصنع والأسعار والكميات.
3. الجرد والتنبيه بانخفاض الكمية.
4. إصدار عروض الأسعار تتضمن الاسم والوصف والعدد والصنع والسعر والصورة.

هذه الوثيقة تصف **الحالة الفعلية للكود الحالي**، ولا تدّعي جاهزية أمنية للاستخدام التجاري بعد.
