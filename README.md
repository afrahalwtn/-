# شركة أفراح الوطن للتجارة العامة — نسخة التطوير

نظام ويب تجريبي للمواد والجرد وتنبيهات انخفاض المخزون وعروض الأسعار والصلاحيات المحددة للمستخدمين. واجهته عربية ومتجاوبة، ويعرض شعار Tapello الأصلي.

## التشغيل الصحيح لهذه النسخة على GitHub

هذا المستودع يعمل حالياً عبر **Node.js / Express** في الملف `server.ts`، وليس عبر خادم Python الموصوف في الإصدارات السابقة.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` ما لم تضبط متغير `PORT` بعنوان مختلف.

## دخول نسخة العرض

- اسم مستخدم الإدارة: `admin`
- كلمة مرور العرض فقط: `admin123456`
- حساب العامل التجريبي: `staff` / `staff123456`

**تحذير أمني:** هذه كلمات مرور تجريبية منشورة في الشيفرة. **لا تستخدم هذه النسخة المكشوفة لإدارة بيانات الشركة الحقيقية أو تنشرها للعامة كما هي.** يجب نقل إعداد الحسابات إلى أسرار الخادم، وتشفير كلمات المرور، وتوفير قاعدة بيانات دائمة، واختبار نظام الأمان قبل الإنتاج.

## حدود النسخة الحالية

البيانات والحسابات والجلسات محفوظة حالياً في الذاكرة داخل `server.ts`، وتُعاد إلى البيانات التجريبية عند إعادة تشغيل الخادم. **لم يُفعّل التخزين المستمر أو SQLite في هذا الإصدار الحالي.** ويجب عدم الخلط بينها وبين الحزمة القديمة المبنية على Python/SQLite.

صور المنتجات تُرفع إلى مجلد `data/images` وفق إعداد الخادم الحالي، لكن عرض الأسعار والمواد والمستخدمين غير محفوظين في قاعدة بيانات دائمة.

## الواجهة الجديدة والمصادر المجانية

- **القالب الحقيقي:** Tabler Dashboard وTabler Icons، بترخيص MIT ومكونات محلية تعمل أوفلاين.
- **الخط:** تجوال Tajawal بأوزان 400–900 (ترخيص OFL 1.1).
- **الألوان:** كحلي عميق، أزرق كهربائي، سماوي، وأبيض؛ مع لون ذهبي محدود للتنبيهات.
- **شعار Tapello:** SVG أصلي مفرغ من الخلفية، ولا توجد بطاقة بيضاء خلفه.

### الرئيسية

تقتصر على عبارة «يــا هـلا و مـرحـبـا»، وشريط بحث بالمواد، وتنبيهات انخفاض الكمية. لا توجد بطاقات أرقام أو وظائف إضافية في الرئيسية.

### البحث وعرض الأسعار

يمكن للإدارة البحث عن أي مادة باسمها أو وصفها أو بلد الصنع، ثم الضغط على «إضافة للوَصل». عند البحث عن مواد أخرى تُجمع **كلها في ورقة عرض أسعار واحدة** تحتوي اسم المادة ووصفها والصنع والصورة وسعر الوحدة والعدد والإجمالي. يمكن تعديل العدد أو حذف المواد قبل الحفظ، وبعد الحفظ يمكن طباعة العرض أو حفظه PDF.

الصور الخاصة تُحمّل بطلبات مصادق عليها حتى عند منع كوكيز الطرف الثالث داخل معاينات Google AI Studio. تقبل الصور الحقيقية JPEG وPNG وWebP، مع تحقق أولي من التوقيع ونوع الملف.

### ملفات الواجهة المستخدمة

- `web/styles.css` — أنماط الأساس.
- `web/tabler-afrah.css` — تكييف Tabler للاتجاه العربي.
- `web/koa-theme.css` — الألوان الكحلية والزرقاء.
- `web/afrah-clean.css` — **الأنماط النهائية الفعالة** للرئيسية والوصل والتجاوب.
- `web/icons.js` — الأيقونات الأصلية.
- `THIRD_PARTY_LICENSES.md` — المراجع والتراخيص.

### الاختبارات

يعمل اختبار الخادم والتحقق من الصورة وعرض الأسعار، بالإضافة إلى اختبار Chromium الفعلي لتسجيل الدخول، وتعدد المواد في الوصل، وضبط الكميات، وحفظ العرض، وعدم تمدد الواجهة على الموبايل والآيباد والحاسبة. تعرض GitHub Actions صوراً للمعاينة باسم `afrah-ui-previews` عند نجاح سير العمل.

## معاينة Google AI Studio

تحديث الملفات على GitHub لا يعني أن معاينة Google AI Studio قد سحبتها تلقائياً. عند ربط المشروع بالمستودع، افتح إعدادات GitHub في Google AI Studio واسحب آخر التغييرات (Pull) من الفرع `main`. إذا لم يكن المستودع مرتبطاً، استورده من خيار Import from GitHub. راجع أي تعارضات قبل تأكيدها.
