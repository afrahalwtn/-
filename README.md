# نظام شركة أفراح الوطن للتجارة العامة

**تطبيق ويب فعلي متعدد الملفات، يعمل من المتصفح دون تثبيت تطبيق على الآيباد أو الهاتف.**

## نطاق العمل المنفذ

- شاشة رئيسية بالعربية: «يــا هـلا و مـرحـبـا»، هوية كحلية/تركوازية وشعار Tapello المرفق، بحث، وقائمة جانبية قابلة للطي.
- المستخدم الأول: إدارة النظام وإضافة المواد وتعديلها وحذفها والجرد والصور وعروض الأسعار والمستخدمين.
- المستخدم الثاني: عرض المواد والجرد والتنبيهات، وصلاحيتان **مستقلتان** لقراءة سعر الشراء وسعر البيع، تتحكم بهما الإدارة.
- جرد الكمية الفعلية لكل مادة وتنبيه داخل النظام عندما تكون الكمية `≤` حد التنبيه.
- عرض أسعار محفوظ مع صورة المنتج، الاسم والوصف والصنع والعدد والسعر، وطباعته أو حفظه PDF عن طريق طباعة المتصفح.

لا يتضمن النظام حسابات أو مبيعات أو تسويقاً أو وظائف تجارية أخرى غير المطلوبة.

## تشغيل على حاسبة ويندوز

يجب تثبيت Python 3.11 أو أحدث على **الحاسبة التي ستشغل الخادم** فقط، مع إضافته إلى PATH.
الآيباد والموبايل لا يحتاجان إلى تثبيت تطبيق.

1. فك ضغط المشروع.
2. شغّل `install_windows.bat` مرة واحدة؛ سيجهّز بيئة Python وينزّل المكتبات وينشئ حساب الإدارة **بكلمة مرور تختارها بنفسك**.
3. شغّل `start_windows.bat`.
4. افتح متصفح الحاسبة على `http://127.0.0.1:8000`.

**مهم:** يحتاج تثبيت المكتبات إلى اتصال إنترنت أول مرة، ثم يعمل النظام داخل الحاسبة بدون إنترنت.

### التشغيل اليدوي

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python scripts\create_admin.py
.venv\Scripts\python -m uvicorn server.main:app --host 127.0.0.1 --port 8000
```

## الآيباد والموبايل والحاسبة معاً

- افتح النظام بالمتصفح فقط. **لكن يجب إبقاء الحاسبة الرئيسية (الخادم) شغالة**، وأن تكون الأجهزة على نفس الشبكة المحلية أو متصلة بخادم يصلون إليه.
- تشغيله من عدة أجهزة يحتاج عنواناً محلياً وتهيئة شبكة صحيحة.
- **لا تستخدم HTTP العادي لتسجيل الدخول عبر الشبكة اللاسلكية الحقيقية**. يجب وضع خادم أمامي HTTPS مع شهادة موثوقة على الآيباد والموبايل، وتفعيل `AFRAH_SECURE_COOKIES=true` و`AFRAH_ALLOWED_HOSTS` المناسب.
- ملف `Caddyfile.example` مثال لإعداد HTTPS محلي؛ يجب إعداد وثوق شهادة Caddy الداخلية على الأجهزة. لا يوجد سيرفر ويب مستضاف تلقائياً ضمن هذه الحزمة.
- خارج الشبكة وبدون اتصال بالخادم، لن تتزامن الأجهزة أو تعمل باستقلالية. التشغيل الفردي على آيباد بدون أي خادم **غير منفذ**.

## قاعدة البيانات

تستخدم النسخة خزنًا محلياً مدمجاً للخادم عبر SQLAlchemy وSQLite داخل `data/` **حتى تكون الحسابات والكميات وعروض الأسعار حقيقية ومستمرة**.
لا يوجد ربط بقاعدة بيانات خارجية؛ أي ربط/ترحيل لقاعدة بياناتك الخاصة مؤجل. طبقة الوصول إلى البيانات منفصلة، ويمكن تهيئتها لاحقاً لقاعدة أخرى.

### الحماية المطبقة

- تحقق الحساب والصلاحيات **داخل الخادم**، ومنع إرسال سعر الشراء/البيع في JSON إذا لم تُمنح الصلاحية؛ وليست مجرد أعمدة مخفية.
- كلمات مرور مشفرة بـ Argon2id؛ لا توجد كلمات مرور افتراضية أو مخزنة في الشيفرة.
- جلسات عشوائية مع تخزين بصمتها فقط على الخادم، وكوكي `HttpOnly; SameSite=Strict` و`Secure` عند تفعيل HTTPS.
- تجديد الدخول بعد تعطيل المستخدم أو تغيير صلاحية الأسعار، وإبطال الجلسات القديمة مباشرةً.
- حماية CSRF، والتحقق من المصدر، ومنع المواقع الغريبة من استدعاء الجلسات.
- قيود على محاولات الدخول، تحقق المدخلات في الخادم، استعلامات SQL آمنة باستخدام ORM، رؤوس CSP وأمان المتصفح.
- تحقق فعلي من ملفات الصور وتحويلها إلى WebP على الخادم، بحد حجمي وبلا وثوق بامتداد الملف.
- الملفات والصور الخاصة لا تُكشف للزائر الذي لم يسجل دخوله.

### ما يلزم قبل الاستخدام التجاري الفعلي

هذا **مشروع عملي قابل للتشغيل والتطوير**، وليس شهادة تدقيق أمني نهائية. قبل عرضه على الإنترنت أو وضع بيانات الشركة المهمة يجب: إعداد HTTPS موثوق، نسخ احتياطي دوري لمجلد `data/`، اختبار استعادة النسخ، مراجعة أمنية مستقلة، تحديث المكتبات، والتحقق من إعدادات الشبكة وصلاحيات الملفات. لا تضع كلمات المرور داخل ملفات المشروع.

## تشغيل الاختبارات

```powershell
.venv\Scripts\python -m pip install pytest httpx
.venv\Scripts\python -m pytest tests -q
```

تم تنفيذ اختبارات وصول غير مصرح به، حماية الأسعار وتغيير الصلاحيات، CSRF، الجرد والتنبيهات، حفظ تاريخ عروض الأسعار، وتحقق الصور. تم تجربة الواجهة في المتصفح بمقاسات الحاسبة والموبايل.

## بنية الشيفرة

```text
server/
  main.py       REST API, roles and routes
  models.py     database models
  schemas.py    validation (Pydantic)
  security.py   Argon2, sessions, CSRF, rate limiting
  database.py   database connection
web/
  index.html    entry document only
  styles.css    responsive RTL design
  app.js        real application functionality
  api.js        centralized authenticated API client
  icons.js      open-source-style icons
  assets/       original Tapello logo in SVG
scripts/
  create_admin.py
  ...
tests/
  test_system.py
```
